# PersonaAI Prototype

Интерактивный desktop-прототип сервиса создания AI-аватаров.

## Что реализовано

- загрузка JPG/PNG с локальным превью;
- выбор одного из шести визуальных стилей;
- анимированный экран генерации;
- четыре варианта результата;
- переключение, скачивание и отправка результата;
- адаптация desktop-композиции под 1920×1080 и MacBook Pro 14″.

Прототип статический: для запуска достаточно открыть `dist/index.html` или раздать папку `dist` любым HTTP-сервером.
